A library of composable modules under `modules/`. Recipes under `examples/` declare intention
(`builtins` + includes) and [ai-rulez](https://github.com/Goldziher/ai-rulez) generates assistant
files.

Define a practice once, reuse it in every project.

## Start here

- [Install and apply](start/install/) - pick a recipe, generate agent files
- [Migrate from ai-rulesmith](start/migrate/) - playbook for old `AI_RULES.json` projects
- [Cursor](start/cursor/) / [GitHub Copilot](start/copilot/) / [Codex](start/codex/) - tool output
- [Library structure](library/structure/) - modules, includes, intention
- [Rules](rules/house/ascii-punctuation/) - browse module rules

## Commands

| Command | What it does |
| --- | --- |
| `task install` | Install tools pinned in `mise.toml` |
| `task apply RECIPE=<name> TARGET=/path` | Copy a recipe into a project |
| `task validate` | Validate dogfood config and every recipe |
| `task build` | Generate this repo's agent files |
| `task docs:dev` | Preview this site locally |
| `task ci` | Validate the library and build the site |
