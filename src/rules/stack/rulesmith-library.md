# Stack: Rulesmith Library

- Follow meta placement and authoring rules for layout; do not restate them here
- Follow pov/mrjk-docs for generated versus handwritten documentation
- Profiles are self contained: no extends; keep Cursor and Codex blocks in sync when both exist
- Keep the root dogfood config rule lists and steps aligned with the profile this project uses
- Handwritten guides live under the docs content tree; rule pages are generated by docs prep
- Run `task validate` after rule or profile changes
- Run `task docs:build` or `task ci` before calling Verify done
- Run `task build` after the dogfood config changes; do not hand-edit generated agent files
- Prefer one-line references to docs over inlining catalogs that go stale
